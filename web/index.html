Install in three steps

  1. 1

    Tap the download button.

    The APK saves to your Downloads folder.

  2. 2

    Open the file and allow installs from this source.

    Android will ask: 'Allow from this source' (or 'Install unknown apps'). Turn it on for your browser, then tap Install.

  3. 3

    Open Grom and tap Start server.

    The status card tells you the truth: Running, Stopped, or Runtime missing.

About Grom

What it is

  • A local server app for Android.
  • A control API bound to 127.0.0.1 by default.
  • An optional public API you enable yourself with a password or Ed25519 key.
  • Open source under Apache-2.0.

What it is not

  • A hosted service, a cloud account, or a wallet.
  • A way to bypass your carrier's NAT.

No traffic is sent anywhere unless you ask for an update check.

Crypto rewards — coming soon
